# Environment example

This directory is the sanitized starting point for an environment branch/fork.

Copy or branch the reusable code and provide environment-specific values through a secure mechanism.

Expected topology:

- edge: <EDGE_IP>
- K8s API VIP: <K8S_API_VIP>
- cp-01: <K8S_CP_1_IP>
- cp-02: <K8S_CP_2_IP>
- cp-03: <K8S_CP_N_IP>
- worker-01: <K8S_WORKER_1_IP>
- worker-02: <K8S_WORKER_2_IP>
- worker-03: <K8S_WORKER_N_IP>
